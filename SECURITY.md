# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in `dockwhy`, please report it privately through [GitHub Security Advisories](https://github.com/prabhnoor12/dockwhy/security/advisories/new).

Do not open a public issue for security vulnerabilities.

Please include:

- A description of the vulnerability.
- Steps to reproduce it, or a proof-of-concept if applicable.
- The affected versions.

We will acknowledge receipt within a few days and work with you to understand and address the issue before public disclosure.
